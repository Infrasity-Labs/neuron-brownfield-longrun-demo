# Standing rules (every role, every arm)

You start every session with no memory of earlier sessions.

- Work only from the task, the files in your working directory, and the rule source the task section "Where the rules come from" names.
- When you apply a rule, say where you got it. If two sources disagree about a rule, name both, give both values, and say which one you followed and why.
- If you cannot find a rule you need, say so. Do not invent a value and present it as a rule.
- Write plain English. Do not use em dashes.
